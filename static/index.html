Por ruta se conservan las texturas relativas del .blend. Al arrastrar, el archivo se copia a data/uploads. También puedes registrar una carpeta completa con .blend y se agregarán todos.

Ajustes

La salida de cada trabajo se define por escena: por defecto se respeta la carpeta guardada en el .blend; puedes cambiarla en los overrides de cada escena.

Formato de salida

Se aplica al renderizar, sobre una copia en memoria: el archivo .blend nunca se modifica. Con «(el del archivo)» se respeta lo que trae cada escena.

Scripts de Python

Se ejecuta después de los overrides, así que puede cambiar cualquier cosa (incluido el formato). Si lanza una excepción el trabajo queda en error con el traceback en su log, sin renderizar. El .blend nunca se modifica: los cambios viven solo en la sesión de Blender que hace ese render.
